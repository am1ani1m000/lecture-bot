## 2026-10-20. Модель эмбеддингов

**Кто предложил:** am1ani1m000 (ядро RAG).
**Статус:** принято.

### Решение

Оставляем локальную модель `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (её название записано в `.env`, переменная `EMBED_MODEL`). На платную модель эмбеддингов не переходим. Высокий порог сходства для ответа «В материалах ответа не нашёл» пока не вводим.

### Почему

1. **Бесплатная и локальная.** Ключи и лимиты не нужны, считает на компьютере. Одна лекция на 50 страниц даёт примерно 100–200 кусков, через внешний API это съело бы дневной лимит запросов.
2. **Понимает смысл, а не только слова.** На учебном тесте (25 пар предложений, скрипт `scripts/try_embeddings.py`) верно 20 из 25 при пороге 0.6.
3. **Понимает русский и английский вместе.** Пара «Кошка спит на диване» и «The cat is sleeping on the sofa» получила сходство 0.98.

Длина вектора у модели 384 числа (проверено запуском).

### Результаты теста по категориям (порог 0.6)

| Категория | Верно | Среднее сходство | Вывод |

| Синонимы | 3 / 3 | 0.76 | Находит тот же смысл другими словами |
| Пересказ | 3 / 3 | 0.80 | То же |

Полный отчёт (пороги, категории, ошибки, все пары): [`docs/experiments/embeddings_test.md`](experiments/embeddings_test.md).

### Известные слабые места и что с ними делаем

1. **Числа.** Модель почти не различает числа, поэтому поиск может поставить первым кусок с другим числом. При `TOP_K = 4` нужный кусок, скорее всего, всё равно попадёт в модель, а числа читает языковая модель. Просим veasoe добавить в `tests/eval/questions.csv` вопросы с числами и формулами.
2. **Отрицание.** Поиск найдёт кусок, но «можно / нельзя» должна прочитать языковая модель. Опираемся на промпт «отвечать строго по тексту из контекста».
3. **Вопрос и ответ получают низкое сходство.** Поэтому порог 0.6 для отказа слишком строгий: бот отказался бы отвечать, хотя ответ есть. Пока берём 4 лучших куска без отсечения.

### Ограничения теста

- Пары короткие и придуманы вручную, а в боте будут куски по 800 символов и настоящие вопросы.
- Порог подобран на тех же 25 парах, на которых проверялся, поэтому 80% это оптимистичная оценка.
- Окончательные выводы делаем на настоящих лекциях и вопросах из `tests/eval/questions.csv`.

### Открытые вопросы

- [x] Нужен ли порог отсечения далёких кусков (например, `MIN_SCORE` в `config.py`)? Если да, какое значение? Подбираем на неделе 3–4 на настоящих вопросах. Это новая константа, её добавление обсуждаем с qsoni.  Решено: `MIN_SCORE = 0.2`, см. «2026-10-22. Порог MIN_SCORE».

## 2026-10-22. Модель для ответов: OpenRouter

### Решение
Ответы генерирует модель через OpenRouter (`LLM_MODEL=openrouter/free`, библиотека `openai`), а не Qwen API из описания проекта.

### Почему
Бесплатный доступ, один ключ, а сменить модель можно одной строкой в `.env`, код не трогаем.

## 2026-10-22. Повторы при перегрузке модели

### Решение
При 429, таймауте и обрыве связи `llm._call_model` повторяет запрос через 2, 5 и 10 секунд. Если все 4 попытки неудачны, бросает `LLMBusyError`, бот ловит её и пишет «модель перегружена, попробуй через минуту».

### Почему
Бесплатная модель часто отвечает 429 на секунду-другую. Паузы с ростом не долбят сервер, а 17 секунд суммарно ещё терпимо для пользователя.

## 2026-10-22. Выжимка длинных лекций в два шага

### Решение
Если текст лекции больше `SUMMARY_PART_CHARS = 12 000` символов, `/summary` сначала делает выжимку каждой части, потом одну сводную из частей.

### Почему
Целая лекция не влезает в контекст бесплатной модели, а обрезка теряет конец лекции.

## 2026-10-22. Порог MIN_SCORE

### Решение
`MIN_SCORE = 0.2` в `config.py`: куски с косинусной близостью ниже порога не идут в ответ.

### Почему
На пробных вопросах нерелевантные куски давали около 0.2 и ниже. Порог взят с запасом вниз, чтобы не терять нужное. Временный, уточняем на неделе 3-4 на настоящих вопросах.

## 2026-10-25. Загрузка модели эмбеддингов

### Решение
`EMBED_MODEL` по умолчанию `paraphrase-multilingual-MiniLM-L12-v2`. Модель грузится один раз, при первом `embed()`, сначала только из кэша, и скачивается, только если её там нет. Векторы нормализованы (длина 1.0). На Linux ставим CPU-версию torch.

### Почему
Без кэша каждый запуск делал десятки запросов к Hugging Face. Ленивая загрузка не тормозит старт бота. Нормализация делает косинусную близость простым скалярным произведением. CPU torch не тянет гигабайты пакетов NVIDIA, видеокарта для такой модели не нужна.
