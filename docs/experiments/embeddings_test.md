# Тест модели эмбеддингов: 25 пар предложений

Дата прогона: 20.10.2026. Модель: `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`, длина вектора 384. Скрипт: `scripts/try_embeddings.py`. Решение по итогам теста: [`docs/DECISIONS.md`](../DECISIONS.md).

**Итог:** при пороге 0.6 верно 20 из 25 пар (80%). Модель хорошо понимает смысл, синонимы и два языка, но почти не различает числа и плохо различает отрицание.

## Как читать

- **Сходство (score)**: число от −1 до 1. Чем ближе к 1, тем ближе тексты по смыслу.
- **Порог**: планка. Сходство не ниже порога значит «похожи», ниже значит «разные».
- **Ожидание**: как должно быть на самом деле. Расставлено вручную.
- **Вердикт**: совпало ли решение модели с ожиданием.
