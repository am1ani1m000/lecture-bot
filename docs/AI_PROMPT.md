# О проекте
LectureBot это Telegram-бот: пользователь присылает PDF с лекцией, а бот делает выжимку (/summary), отвечает на вопросы по документу с указанием файла и страницы (RAG), делает карточки (/cards) и шпаргалку (/cheatsheet). Если ответа в материалах нет, бот так и говорит.
Стек: Python, aiogram, Qwen API (через OpenAI-совместимый клиент), pypdf или pymupdf, Chroma, SQLite, GitHub. Не предлагай других технологий и не усложняй.
RAG: PDF -> текст -> куски примерно по 800 символов -> эмбеддинги -> Chroma с названием файла и номером страницы. Вопрос -> эмбеддинг -> 3-5 ближайших кусков -> промпт «отвечай только по контексту, иначе скажи, что ответа нет» -> Qwen -> ответ с источниками.
Ограничения Telegram: файл до 20 МБ, сообщение до 4096 символов.

# Контракт между модулями (не меняй сам)
- documents.py: load_pdf(path) -> [{text, source, page}]
- search.py: add_chunks(chunks, user_id); search(question, user_id) -> куски с источниками
- llm.py: ask(question, chunks, mode) -> текст, mode: answer / summary / cards / cheatsheet; промпты берёт из prompts/*.txt
- bot.py: Telegram-интерфейс, вызывает всё выше
Пока чужая часть не готова, используем заглушки.
