Telegram-бот для работы с конспектами и лекциями. Отправляешь ему PDF, дальше можно получить выжимку, задать вопрос по тексту, сделать карточки или шпаргалку.
Бот отвечает только по загруженным материалам и называет источник: файл и страницу. Если в лекции ответа нет, он так и скажет.



## 	🔓 Что делает бот

| Команда | Что получишь |
|---|---|
| Отправка PDF | Бот читает файл и запоминает его содержимое |
 Обычный вопрос текстом | Ответ по лекции + строка «Источник: файл, стр. N» |
| `/summary` | Короткая выжимка: главные темы и выводы |
| `/cards` | Карточки «вопрос / ответ» для заучивания |
| `/cheatsheet` | Шпаргалка: определения, формулы, ключевые пункты |
| `/docs` | Список загруженных тобой документов |

## 🚀 Как пользоваться

1. Найди бота в Telegram и напиши `/start`.
2. Отправь PDF с лекцией (до 20 МБ, в файле должен быть текст, не скан).
3. Дождись сообщения «Загружено: N страниц».
4. Задай вопрос или вызови одну из команд выше.

> ⚠️ Сканы без текстового слоя бот пока не читает.

## 🧠 Как это работает

Простыми словами: бот режет лекцию на небольшие куски, по твоему вопросу находит самые подходящие и просит языковую модель ответить, глядя только на них. Такая схема называется RAG.

## 🛠 Технологии

- **Python 3.11+**
- **aiogram 3** (Telegram)
- **pypdf / pymupdf** (чтение PDF)
- **sentence-transformers** (поиск по смыслу, работает локально)
- **ChromaDB** (векторная база) и **SQLite** (пользователи, документы, кэш)
- **OpenAI-совместимый API** (сейчас OpenRouter), модель меняется через `.env`

## ⚙️ Запуск

Подробная пошаговая инструкция: [docs/SETUP.md](docs/SETUP.md).

Коротко:

```bash
git clone https://github.com/ВЛАДЕЛЕЦ/lecture-bot
cd lecture-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполни своими значениями
python bot.py
```
